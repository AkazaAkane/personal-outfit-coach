# 配色、廓形和材质

以下「明确」指小徐在本地转录对应段落明确提出的判断。「应用」是从这些观点迁移到新搭配时可验证的推断。用用户当次的目标排序，尤其注意显高、平衡上下身和表达个性可能需要不同做法。

## 配色

| 观察 | 判断 | 改判条件与转录原文 |
| --- | --- | --- |
| 单件颜色的明暗、鲜灰、冷暖 | **明确**　他的快速评分先看明度，再用饱和度和冷暖修正。其框架里浅、鲜、暖更偏俊美，深、灰、冷更偏硬朗；同一颜色可能在三个维度上指向不同方向。 | **应用**　区分浅灰蓝与亮蓝、深酒红与鲜红；前者的明暗、鲜灰差异能改变整个判断。挂拍受光线影响时按可见色调作暂定判断。<br>**转录原文**　“高明度包含白，俊美加一点五，中明度包含灰不加分，低明度包含黑，硬朗加一点五，高饱和度是俊美加一，中饱和度不加分，低饱和度是硬朗加一，暖色俊美加一，冷色硬朗加一。” “我把明度当成了一个更优先的主导项，饱和度和冷暖更像是在这个基础上的继续修正风格的一个方向。” |
| 想找底色与辅色的关系 | **明确**　同色系是同一色相里换明度或饱和度，邻近色跨到相邻色相，互补色能带来更强反差。黑白灰可以接有彩色。 | **应用**　想安静、连续，先试同色系或相近色；想让一个单品跳出来，可以用互补关系，但再用面积和饱和度控制强度。黑白灰在配色上能衔接，整套风格仍需结合形和质判断。<br>**转录原文**　“邻近色指的是色相环上邻近的两个颜色，那么这两个颜色就可以和参照色进行搭配。” “同色系指的是一个色相中不同的明度或饱和度的颜色，是可以进行搭配的。” “互补色呀，指的是色相环中一百八十度的颜色。一般这类颜色搭配起来呢，冲击力和造型感都是最强的，非常适合于需要抓人眼球的社交场合。” “黑白灰可以和所有颜色进行搭配。” |
| 两件颜色势均力敌，整套缺少主次 | **明确**　用面积法拉开比例，让一色作底、一色做辅助。小面积的颜色如果更鲜或更亮，可能先被看到，最大面积依然能决定底色。 | **应用**　现有大花、亮鞋或强印花已经抓住视线时，优先压低其他颜色的反差；要增加活力时再移一个小焦点。相近颜色边界含混时，可用无彩色内搭或腰带隔开；想保留纵向连续时，先试减少醒目的横向隔离线。<br>**转录原文**　“所谓的面积法呢，就是两个或两个以上的色彩搭配时，如果它们吸引人的程度一样，需要通过调整彼此的面积，让其产生秩序感。” “在尝试焦点法的初期，用作焦点法的颜色明度或饱和度要与主体颜色形成强烈的反差。” “在两个或多个配色关系模糊的颜色中加入另外一个分离色，作为缓冲后，使它们之间的关系明了清晰。” |
| 两件单品风格不同，想让它们自然同框 | **明确**　同色系可以连接不同风格。常春藤案例用藏蓝 Blazer 和浅蓝牛仔裤连成一组，红橙领巾虽然撞色，却通过牛仔文化和牛仔裤连上。 | **应用**　有共同颜色就先试同色系；两色反差大时，找共同的材质、廓形或风格线索。选项太杂时，先回到中性色或无彩色，再决定哪一个彩色值得保留。<br>**转录原文**　“他先利用了蓝色系，将Ivy风格的blazer和工装风格的牛仔裤建立了两种风格的第一个链接。” “它是牛仔们用来防风沙和擦拭汗水的重要工具，也就是它和牛仔裤是同一风格，所以它才可以使用红色。” |
| 要显修长、显轻，还是补某一侧的量感 | **明确**　上浅下深可以把视线提到上半身，上下近色可以减少横向截断，内外深浅对比可以分割躯干的可见面积。 | **改判**　上下重量差明显时，统一颜色可能保留这种差距。上身壮腿细可试外层深、内搭与下装偏浅来补下身；上身薄、腿更有量时，先考虑增加上身的色彩或面料存在感，再看是否要上下同色。<br>**转录原文**　“第一个就是要上浅下深，也就是上半身的明度要高于下半身的明度。” “第三个就是上下同色。” “第三个搭配技巧是满足第二个目标，是减少身上的横向线条” “裤子的颜色上呀，就要和上衣内搭，也就是内浅外深中那个浅的颜色保持一致。” “如果一个上身单薄、下身壮硕的人选择了上下同色，那同一个颜色对于上身和下身身形的收缩或膨胀率是一样的，它只会让你变成一个看起来体积更大或更小的不平衡身材，而对于你所需要的量感的比例却没有起到任何作用。” |

## 廓形

- **先区分衣长和松量。明确**　上短下长会重新分配视觉上的躯干和腿长；上合下合可以让轮廓收整。紧身贴着身体曲线，合体有活动和塑形余量，宽松会更多呈现衣服本身的外轮廓。**改判**　同样想显修长，如果紧身暴露了用户想弱化的部位，改试合体；想留松弛感但担心整套显重，先用一端合体承接另一端的宽松。厚大衣、羽绒服和有叠穿需求的单品要另看放量。
  - **转录原文**　“在显高能力上呢，上短下长大于上长下短。” “紧身就是衣服要紧紧的贴合着我们的身体曲线，而且没有任何修饰体型的功能。” “合体就是衣服与身体有一个合适的距离” “这里需要去除的是大衣和羽绒服，因为它们的面料厚度决定了放量的尺寸。”
- **统一松量和调节身形是两种目标。明确**　他的常春藤混搭案例用上合下合或上宽下宽把不同风格连起来。**改判**　上下身视觉重量不平衡时，他会故意用不对称的松量，例如上身有量、腿细时试上合下宽，上身薄、腿粗时试上宽下合。这里的「合」是对该部位有余量的合体。
  - **转录原文**　“不同风格组合时，要先用统一的上下装廓形，使多种风格建立连接。” 在讨论上身壮、腿细的情形时，他说“个子低的要选择上合下宽，上短下长，这样在优化和调整体型的同时，就可以进一步的显高。” “由于我们的身形啊是上半身单薄、下半身强壮，所以我们需要的廓形主色就应该是上宽下合。”
- **同样收窄轮廓，也可以给出不同气质。明确**　他认为上紧下紧更年轻、更中性，上合下合则更成熟、正式。上宽下合与上合下宽可以保留一处松量，表达比较松弛的都市感。**改判**　先问哪个部位需要活动余量、哪个部位适合突出，再把松量放在那里。
  - **转录原文**　“上紧下紧是最个性、最年轻、最柔美也最中性的廓形组合，而上合下合呢，则变成了最朴实、最成熟。” “上合下宽和上宽下合都适合打造成熟潇洒的。”
- **长外套要看两条线。明确**　他举例用敞开的长大衣和近色内搭、裤子保持纵向连续。**应用**　先比较敞开和扣上，再看裤口是否盖住鞋、厚鞋底是否平衡外套的量感。外套已经偏宽、内外都厚时，试薄内搭和利落的直筒裤；想要更有体量时，再试更宽的裤型。
  - **转录原文（讨论超长大衣）**　“不过搭配这个单品的时候，你需要注意两点：一，大衣里面的衣服一定要做到上下同色；二，如果要显高，就必须敞开穿”

## 材质

| 观察 | 判断 | 改判条件与转录原文 |
| --- | --- | --- |
| 厚薄、挺软、粗细、光泽、织面疏密 | **明确**　在他的「质」框架里，厚、挺、粗糙、哑光、密实偏硬朗，薄、柔、细腻、有光泽、稀疏偏俊美。可以分别观察这些外观特征，再结合形、色看总体。 | 同一面料可能同时挺阔、细腻、有光泽。按对这件衣服影响最大的特征说理由。衣服所属的历史风格也会保留自身气质，例如挺阔的深色 Ivy 仍可保有书卷气。<br>**转录原文**　“这里的面料不是指纤维成分，指的是视觉效果。” “厚硬朗加一，薄俊美加一，挺阔硬朗加一，柔软俊美加一，粗糙硬朗加一，细腻俊美加一，哑光硬朗加一，光泽俊美加一，稀疏俊美加一，密实硬朗加一。” “它之所以有俊美的感觉，是因为它从属的历史风格是艾薇。” |
| 想撑出轮廓，还是减少轮廓体积 | **明确**　厚或挺的面料能支撑局部形状；柔软垂顺的面料能让轮廓落下来，但贴身或版型支撑不足时也会跟出身体曲线。宽松廓形加厚会明显增加体量。 | 需要挺拔但想减量时，比较有局部结构的垂坠面料和整体厚重的面料。想显壮时，高瘦可试宽松加厚，矮瘦可先试合体加厚。**应用**　用同一套只换一件，观察肩、腹或腿哪一处外轮廓改变。<br>**转录原文**　“软的面料塑形性比较差，虽然它可以减少你的占地面积，但是比如如果你有肚子，版型不好的话，它也会如实的呈现你的肚子的形状。” “我们在说宽松廓形，宽松廓形本身已经把你整个人罩住了，身体的形状根本传达不出去。这个时候衣服的体积就是你的体积，面料越厚，你的占地面积也就越大。” “极瘦的人想显壮，可以使用宽松加厚的面料。” “如果你是一个高瘦的人，就选择宽松加厚的面料；如果你是一个矮瘦的人，那么你就选择合体廓形加厚的面料就可以了。” |
| 同样的松量，表面看起来轻还是重 | **明确**　他把粗糙、反光看作会增加视觉体积的因素，细腻、哑光则常使轮廓更收敛；这和布本身占多少空间是两件事。 | **应用**　如果已经有大印花或强光泽，内搭可以用细腻哑光衔接。若整套深色过平、目标又是增加层次，再试同色但有纹理的单品。用现场光线核对反光和透视感。<br>**转录原文**　“细腻的面料要比粗糙的面料更加的显瘦，因为粗糙的面料和厚的面料一样，它会增加空间上的占地面积，而细腻的面料则不会增加这种占地面积。” “厚的面料增加的是一种空间的占地面积，那么光泽的面料增加的就是一种视觉的占地面积。” |
